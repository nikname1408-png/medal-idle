# План проекта «Поле»

> Рабочее название игры — **Поле**. Это мобильная idle/clicker-игра в средневековом
> сеттинге, вдохновлённая Magic Research. Документ — единственный источник правды
> о замысле. Любая сессия с агентом начинается с чтения этого файла.

## 1. Суть игры

Игрок начинает с пустого поля и **нуля энергии**. Пока своего дома нет, энергия
не восстанавливается сама — её даёт только кнопка «Отдых». Кликами игрок добывает
дерево и камень, строит дом, склад и ратушу, нанимает работяг и постепенно
превращает поле в средневековое хозяйство. Цель — проходить эпохи, открывать
постройки, исследования и механики.

Референс: **Magic Research** (мобильная idle-игра). Берём ощущение: клики, ресурсы,
постройки, работяги, постепенное открытие систем.

## 3. Главный экран — спека

### 3.1. Верхняя панель (статичная)

```
[☰]                    Поле                    [🔔]
```

- Слева — бургер-меню. Позже: рынок, что выгодно производить и продавать.
- По центру — название текущей локации/эпохи. Сейчас «Поле», позже меняется
  на «Кузница», «Мануфактура» и т.д.
- Справа — колокольчик уведомлений.

### 3.2. Прокручиваемая часть

Порядок разделов строго сверху вниз. Каждый раздел сворачивается/разворачивается
стрелкой справа от заголовка.

> В v0.3 разделы появляются постепенно: сначала только «Отдых», после 10 отдыхов —
> «Сбор», после 2 дерева — «Хранение» и «Дома». Железо, «Продукция» и остальные
> разделы откроются в следующих версиях.

1. **Отдых**
   - Кнопка «Отдых».
   - У кнопки своя стрелка: разворачивает информацию, сколько даёт за клик
     (например, «+1 энергия за клик»).
2. **Сбор**
   - Кнопки: «Собрать камень», «Собрать дерево», «Собрать железо».
   - У каждой кнопки стрелка с информацией о доходе за клик.
3. **Продукция**
   - Кнопки: «Лесопилка», «Угольная яма», «Кузница».
   - Позже в новых эпохах появятся новые кнопки.
4. **Хранение**
   - «Склад», «Амбар» (позже/по прогрессу), «Банк» (увеличивает лимит золота).
   - Список может расширяться.
5. **Дома**
   - «Дом для работяг».
   - «Исследовательская лаборатория» (исследования зданий/чертежей/предметов).

### 3.3. Статичная нижняя часть

```
[ Дерево ] [ Камень ] [ Железо ] [ Уголь ] [ Золото ]     ← ресурсы
[Поле][Изуч.][Труд][Инв.][Эксп.][Перер.][Стат.][Настр.]   ← вкладки (гориз. скролл)
[############ 100 / 200 (+2.46/с) ############]            ← энергия
```

- **Ресурсы** — строка с иконками и текущим количеством.
- **Вкладки** — квадратные кнопки с иконками, горизонтальная прокрутка:

  2. Изучения
  3. Трудоустройство
  4. Инвентарь
  5. Экспедиции
  6. Перерождение
  7. Статистика
  8. Настройки
- **Энергия** — полоса в самом низу до края экрана, текст вида

## 4. Игровые системы

### 4.1. Энергия

- Старт: **0 / 100**, регенерации нет.
- Пока своего дома нет, энергия не капает сама. Единственный источник — «Отдых»:
  на старте **+1 энергия за клик**.
- После постройки дома «Отдых» даёт **+2**, и дальше +1 за каждый уровень дома.
- Клик по дереву/камню тратит 1 энергию.
- **Свой дом** даёт +1 энергии в секунду за уровень (уровни складываются).
- Энергия не может превысить максимум.

### 4.1.1. Первый запуск (v0.3)

1. Видна только кнопка «Отдых».
2. После 10 нажатий «Отдых» открывается «Собрать дерево».
3. После первого дерева в строке ресурсов появляется значок дерева.
4. После второго дерева открываются камень, «Свой дом» и «Склад».
5. Железо пока закрыто.

### 4.1.2. Сохранение и настройки (v0.3)

- Прогресс автоматически пишется в `localStorage` (ключ `pole_save`) раз в 2 секунды.
- При запуске состояние загружается обратно.
- В настройках есть временная кнопка «Сбросить прогресс» (два нажатия).
  Тема оформления при сбросе сохраняется.
- Темы:
  - **Классический**: кнопки и верхняя панель `#004487`.
  - **Тёмный**: кнопки и верхняя панель `#444444`.
  - Фон и нижняя панель в обеих темах `#222222`.
  - Цвет энергии во всех темах `#BAD118`.

### 4.1.3. Панель разработчика (временная)

- Кнопка «🛠» в верхней панели.
- Позволяет менять:
  - текущую и максимальную энергию;
  - бонус энергии в секунду и за отдых;
  - бонус ресурса за клик;
  - уровни дома и склада;
  - количество любого ресурса и автодобычу в секунду.
- Настройки разработчика **не сохраняются**.
- Перед релизом кнопку и панель нужно удалить.

### 4.1.4. Визуальный стиль (рестайл)

- Плоские разделы без карточек, разделённые тонкими линиями.
- Крупные прямоугольные кнопки по центру, доступные — цветом `--btn`,
  недоступные — `#2b2b2b` с приглушённым красным текстом.
- Шевроны для раскрытия подробностей стоят справа **вне** кнопки.
- Блок «Текущая цель» над списком действий: отдых → дом → склад/улучшения.
- Ресурсы — один общий блок снизу: иконка, название и `текущее / максимум`.
- Нижние вкладки — 8 равных ячеек, иконка + короткая подпись, активная залита `--btn`.
- Полоса энергии: тёмный фон, заполнение `#BAD118`, подпись `⚡ N / max (+X/с)`.

### 4.2. Ресурсы и лимиты

| Ресурс | Источник | Лимит |
|---|---|---|
| Дерево | клик по лесу, лесоруб | склад |
| Камень | клик по камню, каменотёс | склад |
| Железо | клик по железу, шахтёр | склад |
| Уголь | угольная яма | склад |
| Золото | продажа/налоги (уточняется) | банк |

- Без склада ресурсы упираются в базовый потолок и не капают дальше.
- Склад повышает лимит дерева/камня/железа/угля.
- Банк повышает лимит золота.

### 4.3. Постройки (строго по порядку открытия)

1. **Свой дом** — первая постройка. Повышает регенерацию энергии и силу «Отдыха».
2. **Склад** — повышает лимит ресурсов.
3. После своего дома:
   - **Дом для работников** — 1 работник за уровень.
   - **Дом для изучения** — 1 исследователь за уровень.
   - **Лесопилка** — рабочее место для добычи дерева.
4. После изучения «Угольной ямы»:
   - **Угольная яма** — рабочее место: тратит дерево, даёт уголь.
5. Позже:
   - **Кузница** — переработка угля/руды, создание мечей.
   - **Контора управляющего** — менеджер для автоплатежей.

### 4.4. Работники и исследователи

- **Дом для работников** даёт 1 работника за уровень.
- **Дом для изучения** даёт 1 исследователя за уровень.
- Работников назначают во вкладке «Труд»:
  - **Лесопилка**: +0.5 дерева/с с работника, одно место за уровень.
  - **Угольная яма**: партия за 4 с, тратит 1 дерево и даёт 1 уголь.
- Исследователей назначают во вкладке «Изучения»:
  - **Угольная яма**: 30 опыта, +1 опыт/с с исследователя.
  - После изучения открывается одно рабочее место угольной ямы.
- Свободные работники/исследователи видны в шапке вкладок.

### 4.5. Открытые вопросы

- **Откуда берётся золото?** Варианты: продажа ресурсов на рынке, налоги ратуши,
  продажа мечей. Нужно решение до v0.5.
- **Шахтёр даёт руду или железо?** В концепте и то, и другое. Предложение:
  шахтёр даёт руду, кузница плавит руду в железо. Либо упростить: шахтёр даёт
  железо, кузница куёт мечи.
- **Оффлайн-прогресс:** начислять доход за время отсутствия? Обычно да, с потолком.
- **Название игры:** «Поле» — рабочее.

## 5. Архитектура кода

```
medieval-idle/
├── AGENTS.md              # правила для агентов
├── Cargo.toml
├── Dioxus.toml
├── docs/
│   └── PLAN.md            # этот файл
├── assets/
│   └── main.css
└── src/
    ├── main.rs            # точка входа, launch(App)
    ├── game/
    │   ├── mod.rs
    │   ├── state.rs       # GameState, ресурсы, постройки
    │   ├── balance.rs     # числа, стоимости, формулы
    │   └── actions.rs     # чистые функции: клик, покупка, тик
    └── ui/
        ├── mod.rs
        ├── app.rs         # корневой компонент и раскладка
        ├── topbar.rs
        ├── sections.rs    # сворачиваемые разделы
        ├── resources.rs
        ├── tabs.rs
        └── energy.rs
```

Принципы:

- **Логика отдельно от UI.** `game/` не знает про Dioxus. Это позволяет тестировать
  `cargo test` без запуска приложения.
- **Состояние — один `GameState`**, доступный через `Signal<GameState>` или
  контекст. UI только читает и вызывает действия.
- **Баланс — в одном файле** `balance.rs`, чтобы крутить числа без правок логики.
- **Сохранение** — `src/ui/save.rs`: JSON в `localStorage` через `document::eval`
  (работает и в WebView2 на десктопе, и в Android WebView).

## 7. Как запускать

### Быстрая итерация (десктоп)

```powershell
cd C:\Users\boba\Documents\medieval-idle

```

### Android

1. Запустить эмулятор из Android Studio (Device Manager) или:
   ```powershell
   emulator -avd <имя_AVD>
   ```
2. Проверить, что устройство видно:
   ```powershell
   adb devices
   ```
3. Собрать и установить:
   ```powershell
   dx serve --platform android
   ```

### Проверка кода без запуска

```powershell
cargo check
cargo clippy --message-format=short
cargo test
```

## 8. Правила работы с контекстом

- В начале каждой сессии: прочитать `AGENTS.md` и `docs/PLAN.md`.
