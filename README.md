# Поле

Мобильная idle/clicker-игра в средневековом сеттинге.
Rust + Dioxus 0.7, цель — Android.

## Быстрый запуск (Windows)

Самый простой способ — двойной клик по **`run.cmd`**.
Откроется окно игры и терминал; чтобы остановить, закрой окно терминала.

Или из терминала:

```powershell
dx serve --desktop
```

## Запуск на Android

1. Открой Android Studio → **Device Manager** → запусти эмулятор.
2. Дождись, пока эмулятор загрузится.
3. Двойной клик по **`android.cmd`** (или `dx serve --android` в терминале).

## Что уже работает (v0.4)

- «Отдых» даёт энергию. Пока нет дома, энергия сама не восстанавливается.
- После 10 отдыхов открывается добыча дерева.
- После 2 дерева открываются камень, свой дом и склад.
- Дом даёт +1 энергии в секунду за уровень, склад повышает лимит ресурсов.
- Дом для работников и дом для изучения дают по одному работнику/исследователю
  за уровень.
- Лесопилка: назначенные работники добывают дерево.
- Во вкладке «Изучения» исследователи открывают угольную яму.
- Угольная яма: работники тратят дерево и за 4 секунды получают уголь.
- Прогресс сохраняется автоматически (раз в 2 секунды).
- В настройках можно выбрать тему и сбросить прогресс (двумя нажатиями).
- Временная кнопка «🛠» сверху открывает панель разработчика: можно менять
  ресурсы, энергию, уровни построек, работников и скорости добычи.
