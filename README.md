# Поле

Мобильная idle/clicker-игра в средневековом сеттинге.
Rust + Dioxus 0.7, цель — Android.

## Быстрый запуск (Windows)

Самый простой способ — двойной клик по **`run.cmd`**.
Откроется окно игры и терминал; чтобы остановить, закрой окно терминала.

Или из терминала:

```powershell
dx serve --desktop
```

## Запуск на Android

1. Открой Android Studio → **Device Manager** → запусти эмулятор.
2. Дождись, пока эмулятор загрузится.
3. Двойной клик по **`android.cmd`** (или `dx serve --android` в терминале).

## Сборка APK для телефона

Двойной клик по **`build-apk.cmd`** — готовый APK появится в `dist\pole.apk`.
Чтобы сразу установить и запустить на подключённом телефоне:

```powershell
.\build-apk.cmd -Install
```

Что делает скрипт:

1. `dx build --platform android --release --target aarch64-linux-android`
   собирает Rust-библиотеку под ARM-процессор телефона (arm64-v8a).
2. `gradlew clean assembleDebug` упаковывает библиотеку, Kotlin-обвязку и
   ассеты в APK.
3. Скрипт копирует результат в `dist\pole.apk` и проверяет, что внутри есть
   `lib/arm64-v8a/libmain.so`.
4. С флагом `-Install` ставит APK через `adb` и запускает игру.

Почему нужен `--target`: по умолчанию `dx` собирает под x86_64 (эмулятор),
и телефон отвечает `INSTALL_FAILED_NO_MATCHING_ABIS`. Явный таргет
`aarch64-linux-android` даёт библиотеку под реальный телефон.

Требования: `dx`, Android SDK (`ANDROID_HOME`), Java (`JAVA_HOME`),
`adb` в PATH.

## Что уже работает (v0.7)

- «Отдых» даёт энергию. Пока нет дома, энергия сама не восстанавливается.
- После 10 отдыхов открывается добыча дерева.
- После 2 дерева открываются камень, свой дом и склад.
- Дом даёт +1 энергии в секунду за уровень, склад повышает лимит ресурсов.
- Дом для работников и дом для изучения дают по одному работнику/исследователю
  за уровень.
- Лесопилка: назначенные работники добывают дерево.
- Во вкладке «Изучения» исследователи открывают угольную яму.
- Угольная яма: работники тратят дерево и за 4 секунды получают уголь.
- Кузница, шахта, банк, цикл (престиж), статистика, достижения и оффлайн-время.
- Инвентарь с ячейками, экипировкой и крафтом по рецептам; карточка предмета
  открывается тапом.
- Три торговца с живым рынком: спрос, предложение, запас и цены меняются каждые
  5 секунд; покупка и продажа с выбором количества.
- Дом и «Уют» находятся в разделе «Энергия» на вкладке «Поле».
- Системная кнопка «Назад» и свайп слева направо закрывают карточку или экран.
- Прогресс сохраняется автоматически (раз в 5 секунд).
- В настройках можно выбрать тему и сбросить прогресс (двумя нажатиями).
- Временная кнопка «🛠» сверху открывает панель разработчика: можно менять
  ресурсы, энергию, уровни построек, работников и скорости добычи.
