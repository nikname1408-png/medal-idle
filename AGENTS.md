# AGENTS.md

## Что это за проект

Мобильная idle/clicker-игра «Поле» в средневековом сеттинге.
Стек: Rust + Dioxus 0.7, цель — Android.

**Перед любой работой прочитай `docs/PLAN.md`.** Это источник правды о замысле,
спеке экрана и дорожной карте.

## Текущий статус

- v0.7: экономика на данных — каталог предметов и рецептов, инвентарь
  с ячейками и экипировкой, крафт, походы, три торговца с живым рынком
  (спрос/предложение, запас, цены), полноэкранный торговец, карточки предметов
  по тапу, возврат системной кнопкой «Назад» и свайпом. Дом и «Уют» — в разделе
  «Энергия» на вкладке «Поле»; отдельной вкладки «Энергия» больше нет.
  Кузница, шахта, банк, цикл, статистика, оффлайн-время;
  колокольчик открывает текущую цель (ленты подсказок нет), отклик UI сразу
  после действия, замедленная прокачка, автосохранение раз в 5 секунд.
- Игровая логика пока не реализована или реализована частично — сверяйся с планом.

## Команды

```powershell
cargo check
cargo clippy --message-format=short
cargo test
dx serve --platform desktop      # быстрая итерация
dx serve --platform android      # эмулятор/устройство
.\build-apk.cmd                  # APK под телефон -> dist\pole.apk
.\build-apk.cmd -Install          # собрать, установить и запустить
```

## Правила

- Логика игры — в `src/game/`, UI — в `src/ui/`. Логика не должна зависеть от Dioxus.
- Все числа баланса — в `src/game/balance.rs`.
- Не читай и не изменяй `target/`, `.dioxus/`, `build/`, `.gradle/`, `Cargo.lock`.
- Делай минимальные диффы, не переписывай файлы целиком без причины.
- После изменений: `cargo check`, затем `cargo clippy --message-format=short`.
- Не добавляй зависимости без необходимости; новые крейты — только с обоснованием.
- Временную панель разработчика (кнопка «🛠» в верхней панели) нужно удалить перед релизом.
- После завершения вехи обнови `docs/PLAN.md` (статус, решения, следующий шаг).
